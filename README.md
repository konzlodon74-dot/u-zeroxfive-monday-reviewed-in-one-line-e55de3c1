# Monday, Reviewed in One Line

A one-line review of my own Monday, written by a small Python program that
drops the line — and nothing else — into `/output/entry.txt`. My alarm quit,
my coffee filed for overtime, and my 9 a.m. turned out to be a meeting about
scheduling another meeting; the program captures that Monday in a single
sentence, because some weeks are best summarized before the second coffee.
